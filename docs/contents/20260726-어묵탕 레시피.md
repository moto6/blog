# 오늘의 요리 이야기 - 어묵탕 레시피 구하기

- 오늘은 어묵탕을 끓여먹으려고 했는데, 어묵탕에센스가 다 떨어져버려 집에 있는 기초재료를 섞어서 어묵탕 레시피를 역산해서 구해봤다.

- 추산한 결론부터 정리하면 아래와 같고
```
시나리오1 — 인터넷 레시피 참고
:: 다시다멸치 4g · 양조간장 18g · 멸치액젓 3g · 미림 16g · 소금 0.3g
→ 염도 1.02% · 당도 1.10% · 전체 541g

---

시나리오2 — 절충안
:: 다시다멸치 4g · 양조간장 18g · 멸치액젓 3g · 미림 8g · 소금 0.2g
→ 염도 1.02% · 당도 0.67% · 전체 533g

---

시나리오3 — 삼진어묵 당도,염도 매칭
:: 다시다멸치 4g · 양조간장 18g · 멸치액젓 3g · 미림 2.7g · 소금 0.1g
→ 염도 1.01% · 당도 0.38% · 전체 528g
```
- 주요 쟁점은 인터넷에서 많은 유투브와 레시피 참고로 `미림과 간장을 1:1 비율로 유지할때`의 산출레시피와, 벤치마크 제품과 염도%당도를 모두 맞춘 레시피 사이에 3가지 방안을 도출했다
- 세개 다 동시에 같은조건으로 끓여먹어 보고 내 취향을 찾는것도 방법이다.

## 레시피 구하는 대전략  (기초재료에서 어묵탕에센스 환산공식)
추구하는 최종 결과물 제품(이하 어묵탕에센스)은 삼진어묵 사에서 만드는 `삼진어묵 딱한끼 어묵탕 소스 25g` 짜리이다. 이 에센스에다가 물 500mg 을 섞어 2인분 어묵탕 1그릇이 나오는데 이것을 기초재료로 대체할것
기초원료에서 제품을 추산하는 과정은 아래의 논거로 맞춘다
1. 어차피 100% 맛을 똑같이는 못내는것을 인정 - 대충 비슷하게 먹을만한 뭔가만 나오면 된다
2. 최종염도 & 최종당도 & 최종산도 를 비슷하게 맞추면 맛은 비슷할것이다
  ㄴ 염도, 당도, 산도 순서로 맞춘다는게 사람으로 치면 키,몸무게,체질량 지수를 알아내는거고 두 값만 정확하면 대략적인 실루엣은 추정해 낼 수 있는것처럼 추정한다고 가정, 물론 오차가 큼
3. 최종제품을 만들기 위한 원료들의 비율을 역추산해낸다

- 미림: 15mL × 1.08 = 16g

### 염도 검증
- 벤치마크(목표제품) :  1.01% (물 500g + 삼진 어묵탕소스 25g 혼합물의 염도)
- 레시피 염도 추정 : 1.02% (아래 계산산식에 따라)
```
다시다 4g   → Na 865mg
간장 18g    → Na 915mg
액젓 3g     → Na 272mg
─────────────────────────
Na 합 2,052mg → NaCl 5.22g
+ 소금 0.3g (그 자체가 NaCl)
NaCl 총량 = 5.52g
전체 무게 = 541.3g
염도 = 5.52 ÷ 541.3 × 100 = 1.02%  

벤치마크 1.01%와 사실상 동일
```

### 당도 검증

- 벤치마크 제품
```
당류총량 → 2.0g
전체 무게 → 525g
최종당도 → 0.38%
```

- 내 래시피
```
미림 16g   → 당류 4.74g  (탄수화물 32g/100mL 기준, 사실상 전량 당류)
간장 18g   → 당류 0.60g
다시다 4g  → 당류 0.60g
멸치액젓 3g→ 당류 0
──────────────────────
당류 총량 = 5.94g → 최종당도 1.10%
```

- 결론
  - 단맛 인지 역치(0.4~0.5%)를 크게 웃돌기 때문에 국물이나 소스로 섭취했을 때 "은은하게 단맛이 돈다" 혹은 **"단짠 조화가 느껴진다"**고 즉시 인지할 수 있음
  - 벤치마크 제품 = 0.38 Bx 
    - 단맛을 거의 인지하지 못하는 수준이고 (인지역치값 이하), 간장이나 액젓 같은 염분(소금기)과 감칠맛 성분이 섞여 있으면 단맛은 염분에 묻혀 전혀 느껴지지 않음

  - 1.10°Bx (내 레시피) : 혀에서 단맛이 분명하게 느껴지는 수준이나, 인터넷 레피시피인 간장과 미림 1:1 비율을 최대한 지키면서 산출해서 벤치마크 제품보다 당도가 3배 높음

## 이외 잡설

### 소금(NaCl)과 나트륨(Na) 환산법
- 왜 환산이 필요한가?
  - "짜다"고 느끼는 건 **소금(NaCl)** 이지만, 영양성분표에는 **나트륨(Na)** 만 표기됨
  - 소금은 나트륨(Na) + 염소(Cl)가 결합한 화합물이라, 표기된 나트륨만으로는 실제 소금량을 알. 수 없음
  - 따라서 나트륨 → 소금으로 되돌리는 환산이 필요하다 (환산계수 2.542 암기)
- 환산 계수 2.542 는 어디서 나오나?
  - 소금 분자(NaCl) 안에서 나트륨이 차지하는 무게 비율을 역으로 계산한 값
 
| 성분 | 원자량(g/mol) |
|------|:---:|
| Na (나트륨) | 22.99 |
| Cl (염소) | 35.45 |
| **NaCl (소금)** | **58.44** |

- NaCl ÷ Na = 58.44 ÷ 22.99 = 2.542
  - 즉 소금 1g 안에는 나트륨이 약 0.393g(=22.99/58.44)만 들어있음
  - 반대로 나트륨 1g은 소금 2.542g에 해당
  - 그래서 **NaCl = Na × 2.542** 이 항상 성립한다
  - 결론적으로 나트륨(Na)량을 기반으로 소금(NaCl)으로 환산하는 계수는 2.542 를 사용한다
- 또 하나 중요한 팁은 천일염은 염도가 계속 차이나므로 정제염 (한국에서는 한주소금)을 사용한다
```

NaCl = Na × 2.542   (분자량 58.44 ÷ 22.99)
염도(%) = NaCl 총량 ÷ 전체 무게 × 100
```

### 레시피 사용법
- 그램단위 환산 레시피 사용 (부피단위 레시피 아님)
  - 부피단위 (작은술, 큰술, ml) 레시피는 부정확하므로 그램단위 레시피로 환산적용한다. 
  - 정확도가 0.01g 인 전자저울이 필요하다
- 참고하는 외부 레시피는 
  - 액체류 : 큰술=15ml=15g, 작은술 5ml=5g
  - 장류(고추장, 간장) : 밀도 1.2 g/mL 로 환산
  - 가루 : 가루마다 다름

### 그램레시피 환산정보

```
액체류: 밀도 ≈ 1.0 → 15mL ≈ 15g (그래서 물·청주는 1:1)
장류: 소금·당·수분으로 밀도 1.1~1.3 → 같은 부피라도 더 무거움, 
  대충 만들때는 평균값인 1.2 로 환산하고
  정확히 만들때는 밀도를 구해야함 
가루: 입자 사이 공기 때문에 밀도가 제각각 + 누르면 값이 튐 → 공식보다 실측이 정답
```
